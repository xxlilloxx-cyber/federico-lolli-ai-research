# Archived public data exports

These CSV files are preserved for historical traceability but are deliberately
outside the GitHub Pages deployment tree. Their older `validation_loss` or
`final_val_loss` fields do not consistently mean the fresh evaluation at
optimizer step 5,000.

For current public final-study tables and figures, use only:

- `docs/data/long_final_per_seed.csv`
- `docs/data/long_final_aggregate.csv`
- `docs/data/long_validation_trajectories.csv`

See `docs/data/README.md` for the current definitions.
