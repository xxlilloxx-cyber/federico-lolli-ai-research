Project 01 · Method

Linear and quadratic low-rank corrections

The adapter is a trainable correction added beside a frozen GPT-2 projection rather than a replacement for the pretrained model. The backbone weights remain fixed, and only a small low-rank branch is optimized.

This isolates the effect of changing the adapter’s functional form while keeping its trainable parameter budget controlled. LoRA is the direct linear baseline. Symmetric uses the same low-rank matrix shapes but inserts an element-wise square between the first projection and the output projection, producing an activation-dependent quadratic correction rather than a fixed linear update.

Notation

For row activation x ∈ R^(1×d), frozen projection W ∈ R^(d×d_out), and frozen bias b, the pretrained projection is:

y_base = xW + b

The trainable adapter output is added to this frozen projection:

Δy_LoRA = (α/r)(xA)B
Δy_Symmetric = (α/r)((xU) ⊙ (xU))P

Here A,U ∈ R^(d×r) and B,P ∈ R^(r×d_out). Both adapters therefore use two trainable low-rank matrices with matched shapes and parameter count r(d+d_out). LoRA performs two linear projections. Symmetric performs the first low-rank projection, squares the projected activation element by element, and then applies the output projection.

In the controlled rank study, α=4, giving α/r values 4, 2, 1, and 0.5 at ranks 1, 2, 4, and 8. This changing effective scale motivated the separate constant-scale ablation.

Quadratic structure

Δy_j = (α/r) Σ_k P_kj (xu_k)² = xQ_jxᵀ
Q_j = (α/r) U diag(P[:,j]) Uᵀ

Each output coordinate therefore corresponds to a symmetric factorized quadratic form. Projection directions in U are shared across output coordinates, while P supplies output-specific signed coefficients. Because those coefficients may be positive or negative, an individual Q_j need not be positive semidefinite.

(ax₁+bx₂)² = a²x₁² + 2abx₁x₂ + b²x₂²

The square of a projected activation is therefore not limited to independent squared features: it introduces pairwise cross-terms between input dimensions. LoRA remains linear in the adapter input, whereas Symmetric introduces explicit second-order interactions.
