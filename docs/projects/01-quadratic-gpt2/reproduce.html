Project 01 · Reproduce

Reproduce figures or rerun training

Published plots can be reproduced from sanitized CSVs without private checkpoints. Rerunning the 5,000-step experiment requires an appropriate CUDA environment and downloads the public model and dataset.

Setup and smoke test

git clone git@github.com:xxlilloxx-cyber/federico-lolli-ai-research.git
cd federico-lolli-ai-research
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/check_environment.py
PYTHONPATH=. PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/pytest -q tests

Regenerate public data and figures

.venv/bin/python scripts/export_public_long_data.py
.venv/bin/python scripts/generate_public_long_figures.py

long_final_per_seed.csv has one sanitized row per final run: geometry, architecture, seed, local rank, layers, initial, best, final, and test losses. long_validation_trajectories.csv has only step 0 and fresh evaluation points. Legacy aggregate_long.csv and long_results.csv use historical naming and should not replace these definitions.

Rerun the final campaign

.venv/bin/python scripts/run_long_convergence_5000.py
.venv/bin/python scripts/evaluate_long_test.py

This creates private raw logs, metrics, and adapter checkpoints. Do not add those output directories to a public release.
