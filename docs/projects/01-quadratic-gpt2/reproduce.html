Research Project 01 · Reproducibility

Code, data tables, and run protocol

The public release keeps the code and publication-safe result tables required to inspect the reported figures. Local raw run artifacts are preserved separately and are not part of the public Pages payload.

Start locally

python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/check_environment.py
PYTHONPATH=. PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/pytest -q

The experiment was designed for a 4 GB NVIDIA GPU: GPT-2 backbone in FP16/autocast, adapters in FP32, sequence length 128, batch size 1, and gradient accumulation 4. Hardware differences can change runtime and may affect numerical reproducibility.

Primary implementation and final runner

  • src/adapters.py — adapter functions, frozen insertion, parameter accounting, adapter-only checkpoint save/load.
  • src/train.py — training loop, validation, diagnostics, and periodic checkpoints.
  • scripts/run_long_convergence_5000.py — final 18-run 5,000-step campaign definition.
  • scripts/evaluate_long_test.py — held-out test evaluation from final adapter checkpoints.
  • scripts/analyze_long_convergence.py — aggregate tables and final result plots.

Result sources

Final 5,000-step study

aggregate_long.csv contains geometry-level means, standard deviations, AULC, time, throughput, and memory. long_results.csv contains per-seed final values.

Full project traceability

MASTER_RESULTS.csv maps valid historical runs to their experiment family, configuration, seed, metrics, and result directory identifier.

For a narrative account of every stage, read the technical report, including its figures and limitations. The report and tables are source material; site prose only summarizes claims supported by them.

Reproduction boundaries

The original raw experimental logs, system diagnostics, and checkpoints are deliberately not packaged in the public Pages directory. This prevents machine-specific paths and unnecessary operational artifacts from being deployed. The published source code, configurations, aggregate tables, per-seed table, scripts, and report are retained for inspection. The final runner creates new result directories and adapter-only checkpoints when executed locally.
