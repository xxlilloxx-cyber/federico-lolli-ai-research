Project 01 · Reproduce

Reproduce figures or rerun training

Published figures can be reproduced from sanitized numerical tables without raw logs or checkpoints. Rerunning training is a separate operation that needs CUDA, the public model and dataset, and will create private artifacts.

Clone, install, and smoke test

git clone https://github.com/xxlilloxx-cyber/federico-lolli-ai-research.git
cd federico-lolli-ai-research
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/check_environment.py
PYTHONPATH=. PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 .venv/bin/pytest -q tests

The checked-out directory is the repository root; quadratic-transformer was the original local checkout name, not a required subdirectory.

Reproduce public tables and figures

.venv/bin/python scripts/validate_public_long_data.py
.venv/bin/python scripts/generate_public_long_figures.py

long_final_per_seed.csv has one final row per run. long_final_aggregate.csv contains means and sample SDs. long_validation_trajectories.csv contains the pre-update baseline and scheduled fresh validation values. Their schema and legacy-file distinction are documented in the data README; figure inputs and filters are in the figure manifest.

scripts/export_public_long_data.py exports these tables from the private original artifacts and is included for provenance, but it cannot run from the public release alone because those artifacts are intentionally excluded. scripts/generate_public_long_figures.py does run from the published sanitized CSVs.

Rerun the final campaign

.venv/bin/python scripts/run_long_convergence_5000.py
.venv/bin/python scripts/evaluate_long_test.py

This creates raw metrics, logs, and adapter checkpoints locally. Do not add those output directories to a public Pages payload. The long campaign uses fresh runs from step 0; it does not continue historical adapters.

Preview under the GitHub Pages project base path

mkdir -p site-preview/base
ln -s ../../docs site-preview/base/federico-lolli-ai-research
python3 -m http.server 8000 --directory site-preview/base

Open http://localhost:8000/federico-lolli-ai-research/. The repository links in this unpublished review branch use the intended public branch path; before release it should be retained as a stable public branch or replaced with a release tag.
