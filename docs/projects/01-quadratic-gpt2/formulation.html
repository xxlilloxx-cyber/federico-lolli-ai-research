Research Project 01 · Formulation

What the adapters compute

An adapter is a small trainable correction to a frozen GPT-2 projection. It is not a new GPT-2 model trained from scratch.

Symbols, dimensions, and the frozen projection

We use row vectors. The selected projection receives x ∈ R1×d, has frozen weight W ∈ Rd×dout and frozen bias b ∈ R1×dout, and produces ybase = xW + b. In the final experiments d=dout=768. Rank r is the number of latent adapter directions.

LoRA: the matched linear baseline

LoRA learns A ∈ Rd×r and B ∈ Rr×dout while W and b remain frozen:

ΔyLoRA = (α/r)(xA)B;   y = xW + b + ΔyLoRA.

The final campaign sets α=4. Hence a local rank of 8, 4, or 2 has an effective branch scale α/r of 0.5, 1, or 2. B is initialized to zero, so the initial correction is zero; B receives a gradient at the first update, while A has zero gradient until B becomes nonzero.

Earlier quadratic families

All branches below use the implementation’s outer scale α/r. They were explored in earlier, separate studies and were not all final long-run baselines.

Element-wise quadratic

Δy = (α/r)(x ⊙ x)UV.

The square is element by element: it adds feature-wise xi2 terms but does not itself mix feature i with feature j.

Signed quadratic

Δy = (α/r)(x ⊙ |x|)UV.

This keeps the sign while using a quadratic magnitude.

Feature interaction

Δy = (α/r)[(xU) ⊙ (xV)]P.

For component k, (xU)k=ΣixiUik and (xV)k=ΣjxjVjk. Their product contains Σi,jUikVjkxixj, including cross-feature interactions.

Symmetric Quadratic: the final comparison

Symmetric Quadratic learns U ∈ Rd×r and P ∈ Rr×dout:

ΔySym = (α/r)(xU)⊙2P.

For output coordinate j, with uk the k-th column of U,

Δyj = (α/r)ΣkPkj(xuk)2 = xQjxT,
Qj = (α/r)ΣkPkjukukT.

Each outer product is symmetric and rank 1, so rank(Qj) ≤ r. Directions uk are shared across output coordinates; the signed coefficients Pkj are output-specific, so Qj can be indefinite. For two features, (a x1+b x2)2=a2x12+2abx1x2+b2x22: the middle term is the explicit cross interaction. P is zero-initialized, with the same initial-gradient consequence described for LoRA.

Changing local rank simultaneously changes representational rank and α/r. The fixed-budget depth comparison therefore studies their joint effect with placement; it does not identify a pure causal effect of rank alone.

Linear + Quadratic branch

The earlier combined implementation uses a linear and an interaction branch. Its actual wrapper scaling is:

Δy = (α/r)[(αL/rL)(xA)B + (αQ/rQ)((xU)⊙(xV))P].

Thus the branch-specific configured factors are followed by the common adapter scale. This historical formulation is documented here to avoid treating α as an ambiguous symbol across experiments.
