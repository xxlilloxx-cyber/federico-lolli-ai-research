Research Project 01 · Formulation

What the adapters compute

Every adapter is a small trainable correction to a frozen GPT-2 projection. The equations below describe the correction, not a replacement model.

Symbols and dimensions

x ∈ Rd
Input activation to the selected projection.
W ∈ Rd×dout
Frozen pretrained projection weight.
y ∈ Rdout
Output after adding the adapter correction.
r
Low rank, much smaller than d and dout.
α
Configured scaling factor; the implementation applies rank scaling to the adapter branch.

For the final attention-output experiments, d = dout = 768. A rank-r LoRA or Symmetric adapter therefore has r(768 + 768) trainable parameters per insertion point.

Base and linear low-rank correction

We use row vectors, as in the implementation: x ∈ R1×d and W ∈ Rd×dout. The frozen GPT-2 Conv1D projection includes its frozen bias b:

ybase = xW + b

LoRA adds A ∈ Rd×r and B ∈ Rr×dout:

Δy = (α/r)(xA)B,    y = xW + b + Δy

The actual code uses α = 4 and divides by local rank r: the effective branch scales are 0.5 for r=8, 1 for r=4, and 2 for r=2. The product AB is a low-rank linear correction.

Quadratic families explored earlier

Element-wise quadratic

Δy = α(x ⊙ x)UV

Squaring is element by element. It can model feature-wise xi2 effects, but it does not itself form cross-feature xixj products.

Signed quadratic

Δy = α(x ⊙ |x|)UV

The magnitude is quadratic but the sign is retained, so positive and negative activations remain distinguishable.

Feature interaction

Δy = α[(xU) ⊙ (xV)]P

Here U,V ∈ Rd×r and P ∈ Rr×dout. For latent component k, (xU)k = ΣixiUik and (xV)k = ΣjxjVjk. Their product is Σi,jUikVjkxixj, explicitly including interactions between different features.

Symmetric Quadratic: the final long-run comparison

Δy = (α/r)(xU)⊙2P

U ∈ Rd×r and P ∈ Rr×dout. For output coordinate j, writing uk for column k of U gives:

Δyj = (α/r)ΣkPkj(xuk)2 = xQjxT,   Qj = (α/r)ΣkPkjukukT

Each outer product is rank-1 and symmetric, so rank(Qj) ≤ r. Pkj can be positive or negative, so Qj need not be positive semidefinite. The directions uk are shared across outputs; P provides output-specific signed coefficients. For two input features, (x1u1+x2u2)2 includes 2u1u2x1x2, a genuine cross term.

Combined linear + quadratic form

Δy = αL(xA)B + αQ[(xU) ⊙ (xV)]P

This earlier branch experiment allows first- and second-order corrections together. All output factors are initialized to zero, so Δy=0 before the first optimizer update; initially the zero output factor receives gradients and input factors receive gradients after it becomes nonzero.
