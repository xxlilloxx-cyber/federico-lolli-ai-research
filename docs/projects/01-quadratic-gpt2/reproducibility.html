Project 01 · Reproducibility

From evidence to figures

Raw checkpoints stay private; sanitized per-seed tables, configurations, scripts, and provenance are tracked.

Quick verification

git clone https://github.com/xxlilloxx-cyber/federico-lolli-ai-research.git
cd federico-lolli-ai-research
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 pytest -q
python scripts/validation/validate_public_long_data.py
python tools/build_public_site.py

Plot reproduction uses tracked CSVs and does not require model training. Training commands and private-output locations are documented in REPRODUCIBILITY.md.
