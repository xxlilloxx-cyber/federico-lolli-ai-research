Protocol

WikiText-2 uses consecutive 128-token blocks and causal cross-entropy. The backbone is frozen GPT-2 Small. Controlled rank runs adapt zero-based block 0 attn.c_proj, use AdamW at 3×10⁻⁴, gradient accumulation 4, α=4, and seeds 42/123/456. Best recorded validation, final step-5,000 validation, and held-out test from that final checkpoint are separate fields. AG News uses the same backbone and placement with a classification head, a fixed 4,096-example train subset, 1,000-example stratified validation subset, and the original test set.
