Project 01 · Methods

Frozen GPT-2, controlled adapter corrections

The final comparison holds the pretrained backbone, corpus, sequence construction, optimizer protocol, seed set, total adapter parameter budget, and checkpoint rule fixed within each matched geometry.

Model and adapter placement

Hugging Face model and tokenizer identifier: gpt2. GPT-2 Small has 12 zero-based blocks, width 768, 12 heads, and MLP width 3,072. All backbone parameters, including the wrapped Conv1D weight and bias, are frozen. The final campaign wraps only attn.c_proj; block 2 is the third block.

Dataset and loss

Dataset: wikitext, wikitext-2-raw-v1. Records: 36,718 train, 3,760 validation, 4,358 test. Non-empty lines are joined with newline separators, GPT-2-tokenized without added special tokens, and divided into consecutive 128-token blocks; a final shorter remainder is dropped. The model computes causal-LM token-average cross entropy. Validation uses the first eight constructed validation blocks per pass; the held-out test contains 2,213 blocks. Dataset and model revision hashes were not recorded.

Final 5,000-step protocol

Geometry[2] r=8; [0,11] r=4; [0,3,7,11] r=2
Trainable parameters12,288 in every geometry
OptimizerAdamW, lr 3e-4; default betas 0.9/0.999, epsilon 1e-8, weight decay 0.01
ScheduleNo scheduler; no warmup
Batch1; gradient accumulation 4; clipping 1.0
PrecisionFP16 autocast backbone; FP32 adapter parameters
InitializationKaiming-uniform input factors; zero output factors; no adapter dropout
ModeTraining uses train mode and GPT-2 dropout; validation/test use eval mode
Seeds42, 123, 456
ValidationOriginal pre-update measurement, then post-update step 1, every 25 steps, and final step
Test ruleFinal step-5,000 checkpoint, selected before test evaluation

Recorded environment: PyTorch 2.3.1+cu121, Transformers 4.57.6, Datasets 5.0.1, Accelerate 1.15.0.

Study stages

Early 20–1,000-step screens checked execution, stability, placement, and adapter families. Three-seed 2,000-step studies separately tested 6,144 and 12,288 parameter budgets. The final fresh 5,000-step campaign is the main evidence and is not a continuation of historical runs.
