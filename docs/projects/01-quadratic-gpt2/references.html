Research Project 01 · Context

Related work and references

This is an independently evaluated activation-space formulation. Quadratic adaptation and nonlinear low-rank adaptation have clear precedents, so the project does not claim that those broad ideas are unprecedented.

Direct baseline and adapter context

LoRA

Hu et al., LoRA: Low-Rank Adaptation of Large Language Models (ICLR 2022), is the direct controlled baseline. It learns a constant low-rank weight update. This study instead tests an input-dependent quadratic branch with the same parameter count at equal rank.

Nonlinear bottleneck adapters

Houlsby et al., Parameter-Efficient Transfer Learning for NLP (ICML 2019), insert down-projection, nonlinearity, and up-projection modules into frozen Transformers. That broad nonlinear bottleneck is structurally different from the shared symmetric quadratic form tested here.

Related weight-space methods

DoRA decomposes weight magnitude and direction; MoRA uses fixed compression/expansion operators around a square trainable matrix; and HiRA uses Hadamard weight modulation to obtain high-rank update behavior. These methods remain linear in the current activation after the adapted weight is constructed. They were not evaluated as baselines in this repository.

LoRAN and PERA

LoRAN applies a nonlinear transformation to a low-rank weight update. PERA (Findings of ACL 2026, DOI 10.18653/v1/2026.findings-acl.650) polynomially expands low-rank parameter factors before composition. PERA's factor-space square and cross terms differ from the runtime activation map (α/r)((xU) ⊙ (xU))P.

Closest quadratic-form precedent

QuadraNet V2

Xu et al., QuadraNet V2: Efficient and Sustainable Training of High-Order Neural Networks with Quadratic Adaptation (WACV 2026), add a factored quadratic form to a pretrained first-order mapping in a vision-oriented framework. This is a close architectural precedent. The present GPT-2 adapter uses a shared projection matrix U and output-specific signed coefficients in P; scalar-form similarity does not establish full multi-output equivalence.

Comparison scope

Published task scores use different backbones, datasets, budgets, and selection rules. They are literature context and are not combined numerically with the GPT-2 measurements. The repository contains a fuller model comparison, mathematical equivalence assessment, and originality assessment.
