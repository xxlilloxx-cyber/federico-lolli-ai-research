# Manuscript figure exports

These files are publication-build derivatives of canonical vector sources:

  `adapter_architecture_comparison_for_paper.png` derive from
  `results/figures/architecture/adapter_architecture_comparison.svg`;
- `gpt2-attn-adapter-path.pdf` derives from
  `docs/assets/figures/gpt2-attn-adapter-path.svg`;

The PNG used for Figure 1 was rendered from the validated canonical SVG so the
element-wise-square symbol remains readable in the final PDF. It is distinct
from the rejected user-supplied PNG documented in
